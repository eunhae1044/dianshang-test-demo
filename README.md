# dianshang-test-demo
## 极光商城电商系统测试项目文档
> 包含电商系统测试计划、测试用例、缺陷清单、项目总结、需求文档与简易页面原型

## 项目简介
本项目为"极光商城电商Web后台系统手工功能测试练习项目"，完整模拟软件测试工作流程：梳理需求 → 编写测试计划 → 设计测试用例 → 执行测试、提交缺陷 → 输出测试总结。

## 文件结构
- '电商需求文档.md'：电商业务需求梳理
- '电商测试计划.md'：项目测试范围、资源、进度、风险与测试策略
- '电商测试用例.md'：全模块功能测试用例
- '极光商城-缺陷清单.md'：测试过程发现的bug清单，包含缺陷描述、复现步骤、优先级、状态
- '电商总结.md'：项目测试总结，包含测试结果、问题分析、测试评估
- '自定义电商2.0.html'：简易电商页面原型

## 测试范围
Web后台功能测试，覆盖正常业务流程、异常输入、边界场景。

## 测试方法
等价类划分、边界值分析、错误推测法。

## 测试模块
登录、商品管理、订单管理、用户管理等电商核心模块。
